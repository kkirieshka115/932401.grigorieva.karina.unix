# Практическая работа №1 «Скрипт для сборки»

Скрипт `build.sh` на POSIX Shell собирает исходный файл на **C**, **C++** или документ **TeX** во временном каталоге. Имя готового файла берётся из комментария `// Output:` (для C/C++) или `% Output:` (для TeX) в исходном файле.

Временный каталог создаётся командой `mktemp -d` и удаляется при любом завершении скрипта, включая получение сигналов (`HUP`, `INT`, `QUIT`, `PIPE`, `TERM`). После успешной сборки готовый файл копируется в каталог исходного файла.

## Файлы

* `build.sh` — скрипт сборки;
* `hello.c` — пример программы на C;
* `hello.cpp` — пример программы на C++;
* `doc.tex` — пример документа TeX.

## Запуск в Linux

```sh
chmod +x build.sh
./build.sh hello.c
./hello_app

Ожидаемый результат:

Plaintext
